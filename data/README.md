# Nguồn dữ liệu (Data Sources & Owners)

## Nguồn dữ liệu
- **Riot Games API:** Dùng để lấy dữ liệu tĩnh (static data) về thông tin tướng, hệ tộc, và các trang bị hiện tại trong mùa giải.
- **Tactics.tools / MetaTFT (Mô phỏng):** Dữ liệu JSON mô phỏng chứa tỉ lệ chọn (pick rate) và tỉ lệ lọt top 4 của các đội hình meta.

## Trách nhiệm (Owners)
- Chịu trách nhiệm bảo trì file JSON chứa meta và cấu hình API key: Member 3.
