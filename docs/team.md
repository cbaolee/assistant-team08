# Đội ngũ phát triển (Team NN)

Dự án TFT Assistant được xây dựng bởi nhóm 4 thành viên. Dưới đây là cấu trúc phân công thực hiện Pull Request cho bộ khung ban đầu:

- **Member 1 (Philip):** Thiết lập cấu hình dự án gốc (`README.md`, `.gitignore`, `requirements.txt`, `pyproject.toml`).
- **Member 2 (Kim Pong):** Xây dựng lõi backend xử lý logic (`src/assistant/`) và script kiểm tra môi trường (`scripts/check_env.py`).
- **Member 3 (Bội Anh):** Lên kế hoạch giao diện overlay và định nghĩa cấu trúc dữ liệu (`ui/README.md`, `data/README.md`).
- **Member 4 (Nhật Quỳnh):** Thiết lập môi trường kiểm thử khói (smoke tests) và viết tài liệu dự án (`tests/`, `docs/README.md`, `docs/team.md`).
