# UI Mockup: Data Sources Display

This document illustrates the design for displaying data source citations directly below composition (comp) or item recommendations in the TFT Assistant's In-game Overlay. The goal is to help users understand the reliability and recency of the provided data.

## Example 1: Comp recommendation based on Meta statistics
When the virtual assistant recommends a strong comp (Tier S/A) based on win rate and pick rate from third-party analytics platforms.

**UI Display (Mockup):**
> ### 🏆 Comp: Fated - Tier S
> **Champions:** Syndra, Sett, Thresh, Aphelios, Amumu, Illaoi, Yasuo
> **Core Items (Syndra):** Blue Buff, Jeweled Gauntlet, Rabadon's Deathcap
> 
> ──────────────────────────────
> 📊 *Source: MetaTFT | Patch: 14.8 | Top 4 Rate: 56.4%*


## Example 2: Static information lookup
When the virtual assistant provides core information about base stats, champion abilities, or item recipes.

**UI Display (Mockup):**
> ### ⚔️ Item: Bloodthirster
> **Recipe:** B.F. Sword + Negatron Cloak
> **Effect:** Grants 20% Omnivamp. Once per combat: At 40% Health, gain a 25% maximum Health shield that lasts up to 5 seconds.

> 🛡️ *Official Data: Riot Games API (Static Data)*
