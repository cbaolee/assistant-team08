# TFT Smart Assistant

Dự án trợ lý ảo thông minh hỗ trợ người chơi Teamfight Tactics (TFT). Trợ lý cung cấp các gợi ý về đội hình (comps), cách ghép trang bị (items) tối ưu, và phân tích các lõi công nghệ (augments) dựa trên dữ liệu meta hiện hành.

## Hướng dẫn cài đặt
1. Chạy `python scripts/check_env.py` để kiểm tra môi trường.
2. Cài đặt các phụ thuộc: `pip install -r requirements.txt`.
